# SnipTools

SnipTools is a comprehensive suite of developer and productivity tools built with security, speed, and visual excellence in mind.

## 🚀 Quick Links

- [Development Guide](DEVELOPMENT.md)
- [Deployment Steps](DEPLOYMENT.md)

## 🛠 Tech Stack

- **Backend**: PHP 7.4+ (Custom Framework)
- **Database**: MySQL
- **Frontend**: Vanilla JS, CSS (Tailwind CSS for some components)
- **Icons**: Font Awesome 6

## 📂 Key Directories

- `config/`: Application configuration and tool definitions.
- `includes/`: Core logic, database abstraction, and reusable components (header, footer, etc.).
- `views/`: Page templates and tool-specific implementations.
- `public/`: Public-facing entry points and static assets.
- `scripts/`: Maintenance and migration scripts.
